## 题目描述

给定整数 `money`（总钱数）和 `children`（儿童数量），按以下规则分配：

- ✅ 所有钱必须分完
- ✅ 每人至少分 **1** 美元
- ❌ 没人能拿到 **4** 美元

> 求**最多**有多少个儿童拿到**恰好 8 美元**。若无可行方案，返回 `-1`。

---

## 思路分析

目标是最大化"恰好 8 美元"的人数，很自然地想到**贪心**——优先让尽可能多的人拿到 8 美元。

### 第一步：保底分配

先给每人 1 美元，满足"至少 1 美元"的底线。此时剩余钱数为 `money - children`。

### 第二步：全力冲 8 美元

每人已有 1 美元，要凑到 8 美元还需补 **7 美元**。因此最多可以凑出：

```
count = min(剩余钱数 / 7, children)
```

### 第三步：处理两个边界 case

<table style="width:100%;display:table"><colgroup><col style="width:90px"><col></colgroup><tbody>
<tr><td>💰 钱多了</td><td>`children == 0 && money > 0`：所有人都 8 美元了，但钱没分完，多出的钱只能塞给某人，他不再是"恰好 8 美元" → `count-1`</td></tr>
<tr><td>⚠️ 踩到 4</td><td>`children == 1 && money == 3`：1 + 3 = 4 美元，违反规则，必须拆掉一个 8 美元来救场 → `count-1`</td></tr>
</tbody></table>

## 代码实现

```java
class Solution {
    public int distMoney(int money, int children) {
        // 每人先给 1 美元
        money -= children;
        // 如果每人分配不到1美元，直接返回-1
        if (money < 0) return -1;
        // 贪心：尽可能多地凑出 8 美元（每人再补 7 美元）
        int count = Math.min(money / 7, children);
        // 先按照能分配的人数分配 8 美元
        money -= count * 7;
        // 减少已分配8美元的人数
        children -= count;
        // 如果所有孩子都已分配8美元，但是还有钱，或剩余孩子为1人且余钱刚好为3美元，但因为不能分配4美元，必须拆掉一个8美元来救场
        if ((children == 0 && money > 0) || (children == 1 && money == 3))
            count--;

        return count;
    }
}
```
